TASK 29-11-00-400-801 - GREEN SYSTEM ENGINE PUMP - Removal/Installation

1. Reason for the Job

Replacement of the green system engine pump as a result of a fault isolation finding.

2. Job Set-up Information

Parts required (see IPC 29-11-00 FIG 1 for effectivity and approved alternates):

PART NUMBERNOMENCLATUREQTYIPC REF
D23935801200VALVE - CHECK, GREEN SYSTEM ENGINE PUMP229-11-00 FIG 1
D23936962000CONNECTOR - ELECTRICAL, GREEN SYSTEM ENGINE PUMP129-11-00 FIG 1
D28868460400SWITCH - PRESSURE, GREEN SYSTEM ENGINE PUMP129-11-00 FIG 1
D27387260300GASKET, GREEN SYSTEM ENGINE PUMP229-11-00 FIG 1
WARNING: Do not work on pressurized lines. Injury to persons can occur.
CAUTION: Install protective caps on open lines to prevent contamination.

3. Procedure

  1. Make sure the aircraft is safe for maintenance and the applicable circuit breakers are open and tagged.
  2. Release system pressure and disconnect the lines from the green system engine pump.
  3. Remove the attaching hardware and remove the VALVE - CHECK, GREEN SYSTEM ENGINE PUMP.
  4. Install new seals. Lubricate seals with the approved fluid before assembly.
  5. Install the replacement VALVE - CHECK, GREEN SYSTEM ENGINE PUMP and torque the attaching hardware.
  6. Do the operational test. Examine the connections for leaks.

4. Close-up

Remove tools and tags. Close access panels.
