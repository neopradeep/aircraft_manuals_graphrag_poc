TASK 80-31-00-400-801 - START CONTROL RELAY - Removal/Installation

1. Reason for the Job

Replacement of the start control relay as a result of a fault isolation finding.

2. Job Set-up Information

Parts required (see IPC 80-31-00 FIG 1 for effectivity and approved alternates):

PART NUMBERNOMENCLATUREQTYIPC REF
60-12960-28PUMP - TRANSFER, START CONTROL RELAY180-31-00 FIG 1

285-35863-15FITTING - ELBOW, START CONTROL RELAY480-31-00 FIG 1
WARNING: Do not work on pressurized lines. Injury to persons can occur.
CAUTION: Install protective caps on open lines to prevent contamination.

3. Procedure

  1. Make sure the aircraft is safe for maintenance and the applicable circuit breakers are open and tagged.
  2. Release system pressure and disconnect the lines from the start control relay.
  3. Remove the attaching hardware and remove the PUMP - TRANSFER, START CONTROL RELAY.
  4. Install new seals. Lubricate seals with the approved fluid before assembly.
  5. Install the replacement PUMP - TRANSFER, START CONTROL RELAY and torque the attaching hardware.
  6. Do the operational test. Examine the connections for leaks.

4. Close-up

Remove tools and tags. Close access panels.
