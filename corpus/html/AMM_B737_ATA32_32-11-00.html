TASK 32-11-00-400-801 - MAIN GEAR SHOCK STRUT - Removal/Installation

1. Reason for the Job

Replacement of the main gear shock strut as a result of a fault isolation finding.

2. Job Set-up Information

Parts required (see IPC 32-11-00 FIG 1 for effectivity and approved alternates):

PART NUMBERNOMENCLATUREQTYIPC REF
65-24408-22ACTUATOR - LINEAR, MAIN GEAR SHOCK STRUT132-11-00 FIG 1
60-17972-16SOLENOID, MAIN GEAR SHOCK STRUT232-11-00 FIG 1
65-87182-11FILTER ELEMENT, MAIN GEAR SHOCK STRUT132-11-00 FIG 1
162-68138-03WASHER - LOCK, MAIN GEAR SHOCK STRUT132-11-00 FIG 1
WARNING: Do not work on pressurized lines. Injury to persons can occur.
CAUTION: Install protective caps on open lines to prevent contamination.

3. Procedure

  1. Make sure the aircraft is safe for maintenance and the applicable circuit breakers are open and tagged.
  2. Release system pressure and disconnect the lines from the main gear shock strut.
  3. Remove the attaching hardware and remove the ACTUATOR - LINEAR, MAIN GEAR SHOCK STRUT.
  4. Install new seals. Lubricate seals with the approved fluid before assembly.
  5. Install the replacement ACTUATOR - LINEAR, MAIN GEAR SHOCK STRUT and torque the attaching hardware.
  6. Do the operational test. Examine the connections for leaks.

4. Close-up

Remove tools and tags. Close access panels.
